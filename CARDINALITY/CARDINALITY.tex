\section{Cardinality}
The most difficult part of set theory is the concept of cardinality. The cardinality of a set is 
a measure of the "size" of the set, and it can be defined in several different ways. In this 
section we will define the concept of cardinality in a formal way, providing two definitions, one 
that works only if AC (Axiom of Choice) is assumed to be true and one that works 
even if AC is neither assumed true nor false.
