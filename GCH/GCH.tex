\section{Generalized Continum Hypotesis (GCH)}
In this chapter we will discuss the generalized continum hypotesis (GCH) and its implications. To put it simply, 
the GCH states that for every pair of cardinal numbers $k$ and $\bar{k}$ such that $k \leq \bar{k} < 2^k$ it is the case 
that $k = \bar{k}$. This means that there are no cardinalities between $k$ and $2^k$. It has been proven that the GCH is
indpendent from ZF set theory, which means that it can be assumed to be true or false without any contradiction. It's not indpendent
from ZFC tho, since it can be proven that the generalized continum hypotesis implies the axiom of choice.
